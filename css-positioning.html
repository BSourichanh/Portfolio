Résumé complet des 5 modes de positionnement CSS et leurs différences.

Preuve de travail :

Explication des différences entre static, relative, absolute, fixed et sticky avec exemples visuels dans le code HTML/CSS.

position: static (Par défaut)

  • Flux normal : L'élément suit l'ordre naturel d'affichage du document HTML.
  • Propriétés inactives : top, bottom, left, right et z-index n'ont **aucun effet**.

position: relative

  • Décalage par rapport à lui-même : Positionné dans le flux normal, puis décalé par rapport à sa position d'origine.
  • Espace réservé : L'espace initial de l'élément reste réservé dans le flux (aucun impact sur le positionnement des éléments voisins).
  • Rôle de conteneur : Sert très souvent d'élément de référence (parent) pour un enfant en position: absolute.

position: absolute

  • Extrait du flux : Retiré du flux normal du document (ne réserve aucun espace, les autres éléments se placent comme s'il n'existait pas).
  • Parent de référence : Se positionne par rapport au premier ancêtre qui possède une position autre que static (généralement un parent relative). Si aucun ancêtre n'est positionné, il se réfère au <html> / viewport.

position: fixed

  • Extrait du flux : Retiré du flux normal.
  • Fixé au Viewport : Se positionne par rapport à la fenêtre du navigateur (viewport). Il reste **immobile lors du défilement / scroll**.
  • Utilisation courante : Barres de navigation (headers sticky/fixed), boutons "Retour en haut", modales, badges flottants.

👉 Regardez en bas à droite de votre écran : le widget vert est en position: fixed.

position: sticky

  • Hybride (Relative + Fixed) : Se comporte comme relative tant qu'on ne scrolle pas jusqu'à son seuil défini (ex: top: 0). Une fois le seuil atteint, il devient "collant" (comme un fixed) à l'intérieur de son conteneur parent.
  • Dépendance du parent : Il reste collé uniquement tant que l'utilisateur défile à l'intérieur du conteneur parent.
